# Forest Discovery

A small browser game about wandering through an old forest that feels alive: pixel art trees that ripple in the wind, gusts you can see and hear, and nothing to win or lose. It is plain JavaScript on a canvas, with no engine and no build step, and the whole base is meant to stay under 1 MB.

**Play:** https://koetsuji.github.io/forest-discovery/

**Credit:** the wind technique (leaf clumps that loop one after another along the wind, with gusts on top) comes from Kimo, asynkimo on X. See [his video](https://x.com/asynkimo/status/2121230694860890582) and [his article](https://www.spritecook.ai/blog/pixel-art-trees-wind-animation). This repo is a new implementation of the idea in JavaScript. The interface fonts are Geist by Vercel, under the SIL Open Font License.
