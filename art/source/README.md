# art/source

Sprites exactly as they were generated. These are the inputs of the art pipeline. Nothing in this folder is loaded by the game.

- PNG at the original size. No screenshots, no JPEG, no resizing.
- One file per sprite, named `kind-number.png`: `oak-01.png`, `pine-01.png`.
- The rules every sprite must pass are in docs/art-guide.md.
